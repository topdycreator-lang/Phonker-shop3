# Phonker Shop: бот + сайт + Telegram Mini App

## Как связаны части
- `main.py` запускает Telegram-бота и `web_api.py`.
- `web_api.py` отдаёт сайт из папки `site/` и API (`/api/...`) на одном порту.
- `site/` содержит Mini App: он использует относительные `/api/...` запросы, поэтому отдельный адрес API не требуется.
- `tunnel.py` поднимает Cloudflare Quick Tunnel на тот же локальный порт. Без постоянного домена адрес будет временным и может измениться после перезапуска.
- В Telegram меню бота автоматически обновляется, когда туннель сообщает публичный HTTPS-адрес.

## Запуск в Termux
1. Распакуй весь ZIP в одну папку, не отделяя `site/` от Python-файлов.
2. Скопируй `.env.example` в `.env`.
3. В `.env` вставь **новый** токен бота. Старый токен и старый секрет оплаты, попавшие в предыдущий архив/переписку, лучше перевыпустить.
4. Если используешь Platega, вставь свежие merchant ID и secret. Без них сайт и бот запускаются, но Platega-платежи недоступны.
5. В Termux запусти: `bash start.sh`.

## Порт
Локальный порт по умолчанию: `1230`. Веб-сервер и туннель используют одинаковый порт. Если хостинг выставляет переменную `PORT`, она имеет приоритет, чтобы приложение не конфликтовало с портом платформы.

## Важно
Не запускай отдельно ZIP с одним сайтом: он без API магазина не сможет оформлять покупки. Используй интегрированный архив, в котором папка `site/` лежит рядом с `main.py` и `web_api.py`.
